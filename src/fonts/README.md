# Theme fonts

Generated by `tools/gen_gfx_font.py` from Liberation Sans (Regular and Bold,
`/usr/share/fonts/liberation/` on the build machine), which is licensed under
the SIL Open Font License 1.1. These headers are bitmap renderings of it;
regenerate them rather than editing them.

| Header | Source | Size | Use |
|---|---|---|---|
| `SansBold10pt.h` | LiberationSans-Bold | 10 pt | headers |
| `SansBold7p5pt.h` | LiberationSans-Bold | 7.5 pt | list rows |
| `Sans7p5pt.h` | LiberationSans-Regular | 7.5 pt | values |
| `Sans6p25pt.h` | LiberationSans-Regular | 6.25 pt | help and descriptions |

Sizes are picked by capital height against the FreeSans sizes the bench asked
for (FreeSans 10/8/7 pt → 14/11/9 px capitals). Liberation's capitals are
taller per point than FreeSans's.
